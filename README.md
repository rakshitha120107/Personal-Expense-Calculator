# Personal Expense Calculator
Enter income and expenses, see savings, category breakdown, suggestions and month-to-month progress.

## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Install the "Live Server" extension, right-click `index.html` > Open with Live Server.
   (Or just double-click `index.html` to open it in a browser.)

## Files
- index.html - page structure
- style.css - styles (light/dark, responsive)
- script.js - calculations, suggestions, saving months (localStorage)

Data is saved in your browser's localStorage.
